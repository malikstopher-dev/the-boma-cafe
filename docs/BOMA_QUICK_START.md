# The Boma Cafe — Quick Start Guide

**10-minute staff introduction**  
Full details: see `BOMA_CLIENT_HANDOVER.md`

---

## Your Screen

| Role | Login At | Your Screen |
|------|----------|------------|
| **Owner** | `/admin/login` | Owner Dashboard → full access to everything |
| **Manager** | `/admin/login` | Admin Dashboard → Operations, orders, bookings, inventory |
| **Kitchen** | `/staff/login` | Kitchen order board |
| **Bar** | `/staff/login` | Bar order board |
| **Waiter** | `/staff/login` | Waiter app (food, drinks, tables, orders) |

---

## Login

**Admin (Owner/Manager):**
1. Go to `your-site-url/admin/login`
2. Select your name from the dropdown
3. Enter your password
4. You land on the dashboard

**Staff (Kitchen/Bar/Waiter):**
1. Go to `your-site-url/staff/login`
2. Select your role (Kitchen, Bar, or Waiter)
3. Enter the shared password for your station
4. You land on your board

Waiters: after station login, use your personal PIN to access the waiter ordering app.

---

## Waiter — Placing an Order

1. Open the **Tables** tab → tap your table on the floor plan
2. Open **Food** or **Drinks** tab → browse and add items to your cart
3. Open **Cart** tab → review items, adjust quantities, add notes
4. Tap **Submit Order**
5. The order appears on Kitchen/Bar boards automatically
6. Check the **Done** tab for live status updates (real-time)

**You can:** create orders, view history, mark orders served/completed, view bookings, send messages.  
**You cannot:** cancel submitted orders (ask Kitchen, Bar, or Admin).

---

## Kitchen — Preparing Orders

1. See new orders in the **New** column
2. Tap **START PREP** → choose a time estimate (5, 10, 15, 20, 30, 45, or 60 min) or start without
3. Order moves to **Preparing** with a live countdown
4. When done, tap **MARK READY**
5. Order moves to **Ready** → the waiter collects it

**Timer colours:** Green = on track, Amber = almost due, Red pulsing = overdue.  
**Default target:** 15 minutes.

---

## Bar — Preparing Orders

Same as Kitchen, but:
- **Default target:** 5 minutes
- **Quick times:** 2, 5, 8, 10, 15, 20 minutes
- You only see drink orders

---

## Admin — Managing Orders

1. Go to **Orders** in the sidebar
2. Online orders appear as **pending** — tap **Accept** to confirm them
3. Track all orders by status (Pending, Confirmed, Preparing, Ready, Completed)
4. Kitchen/Bar handle preparation; Waiter handles served/completed

---

## Admin — Bookings

1. Go to **Bookings** to see all function bookings
2. Change status: confirm, complete, cancel, or refund
3. Go to **Quotes** to view/re-send PDF quotations
4. Go to **Pricing** to configure venue fees and packages
5. Go to **Availability** to block dates

---

## Admin — Receiving a Delivery

1. Go to **Receiving** (shows only POs that are due)
2. Click the PO → enter quantity received + invoice number for each line
3. If short on an item, select a reason (Supplier Shortage, Backorder, etc.)
4. Tap **Receive** — stock and cost update automatically, an invoice is created

---

## Admin — Stock Count

1. Go to **Stock Counts** → **New Count**
2. Select a location → the system snapshots expected balances
3. Count each product → type the physical quantity
4. Tap **Submit** → a manager taps **Approve**
5. Differences are posted as adjustments to the ledger

---

## Realtime

Changes should appear on other devices automatically within seconds:
- New order → Kitchen/Bar board updates
- Order marked Ready → Waiter app updates
- Stock adjusted → Dashboard updates

**If something does not update:** press Refresh, or close and reopen the tab.

---

## Basic Troubleshooting

| Problem | Try This |
|---------|----------|
| Order not on board | Refresh; check if Admin confirmed it (online orders need confirmation) |
| Board frozen | Refresh; check internet connection |
| Status looks wrong | Refresh — another device may have already updated it |
| Stock looks wrong | Check Transactions page; run a Stock Count to verify |
| Cannot log in | Check you are using the right URL and password; ask Admin for help |
| Upload failed | Check connection; try a different browser |

---

## When to Contact Support

Contact system support when:
- Something persists after refreshing
- You see an error message you do not understand
- Stock levels do not match what you expect after checking Transactions
- A booking or order is stuck in an unexpected state
- You cannot log in after checking your credentials

**Provide:** the page you were on, the time, your role, what you were trying to do, and any error message shown.

**Never share** your password or PIN with anyone, including support staff.
